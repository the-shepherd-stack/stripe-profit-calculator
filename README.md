# Stripe Profit Calculator

Free static Stripe fee + profit margin calculator for digital products.

Features:
- coupon discount math
- VAT-inclusive revenue split
- affiliate payout modeling
- refund reserve modeling
- net profit and break-even price outputs
- shareable scenario URLs
- preset scenarios for templates, courses, and micro-SaaS

Local verification:
- `node --test tests/*.test.js`

Deployment target:
- Vercel static site
